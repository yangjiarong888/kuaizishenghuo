# 外卖地址自动新增设计

## 目标

外卖结算打开“配送至”地址簿后，按 `existing`、`auto` 或 `add` 策略选择地址。`auto` 在没有合格地址时自动新增，`add` 强制新增；新增成功必须回读验证后才能继续支付与下单。

## 数据与安全边界

- 新增地址只从本机环境变量读取：`TAKEOUT_ADDRESS_CONTACT`、`TAKEOUT_ADDRESS_PHONE`、`TAKEOUT_ADDRESS_SEARCH`、`TAKEOUT_ADDRESS_DETAIL`。
- `auto` 仅在四项数据完整时允许进入新增分支；`add` 同样在创建 Driver 前完成校验。
- 日志不输出完整联系人、手机号、搜索词或详细门牌；手机号最多记录尾号掩码。
- 默认策略为 `existing`，不改变现有命令的写入行为。
- COD 或电话通知要求最终选中的地址包含手机号。
- 新增地址会持久化到当前真实账号；脚本不自动删除地址。

## 页面流程

1. 结算页打开配送地址弹层。
2. `existing` 选择符合序号、摘要及手机号约束的已有地址。
3. `auto` 先执行已有地址选择；无合格地址时点击“新增地址”。
4. `add` 直接点击“新增地址”。
5. 在定位地址页确保定位权限开启，输入搜索词并选择明确结果。
6. 回到地址表单填写联系人、手机号和详细地址并保存。
7. 回到地址簿或结算页，以手机号尾号和非敏感地址摘要回读验证；地址簿场景下选中新增地址。
8. 验证成功后才继续支付方式、优惠券、备注、配送时间与提交订单。

## 失败语义

任一必填字段缺失、搜索结果不唯一、字段不可填写、保存未返回、回读不匹配或手机号约束不满足时，当前命令失败并停止，不执行下一条业务命令。
