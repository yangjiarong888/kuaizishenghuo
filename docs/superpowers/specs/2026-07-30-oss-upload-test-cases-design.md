# OSS 上传链路测试用例工作簿设计

## 目标

依据《OSS 上传链路测试说明》，生成一份可直接执行、可追踪结果、便于后续维护的详细 Excel 测试用例。测试基线为 `origin/release`，重点验证上传服务迁移后的兼容性、数据一致性和故障回滚能力。

## 交付物

输出一个 Excel 工作簿，包含以下工作表：

1. **用例说明与统计**
   - 测试范围、环境依赖、优先级定义和执行约定。
   - 按模块、优先级和测试类型统计用例数量。
   - 记录原始需求文档链接。
2. **核心测试用例**
   - 覆盖正常上传、格式与内容校验、文件大小和像素边界、原图清晰度、缩略图、水印、批量回滚、视频首帧、媒体删除、OSS 异常、关闭 OSS 和业务闭环。
   - 字段包含：用例编号、模块、标题、类型、优先级、前置条件、测试数据、步骤、预期结果、数据库/OSS 检查点、自动化建议、执行结果、缺陷编号和备注。
3. **业务入口回归矩阵**
   - 覆盖文档列出的商品、房源、充值、评价、售后、头像、营业执照、城市媒体、App、WAP、PC、小程序码和 IM 群头像等业务入口。
   - 每个入口至少标记正常图片、异常图片和 OSS 失败三类覆盖；视频入口额外覆盖 MP4 与首帧。
   - 文档未展示明确接口地址的入口，以业务场景作为可追踪标识，接口地址留作执行前补录。
4. **测试数据清单**
   - 定义可复用的合法、非法和边界测试文件，以及预期用途和生成/准备要求。
5. **执行记录**
   - 预留测试轮次、环境、执行人、日期、通过/失败/阻塞数量、缺陷链接和结论。

## 用例设计原则

- 使用等价类、边界值、错误推测和场景法。
- 优先级分为 P0、P1、P2：
  - P0：上传主链路、数据一致性、OSS 故障回滚和核心业务闭环。
  - P1：白名单、边界、水印、缩略图、视频和删除能力。
  - P2：兼容性、展示侧低清误用检查和辅助场景。
- 通用能力只在“核心测试用例”中详细描述，业务入口通过回归矩阵引用核心用例，避免大量重复。
- 每条用例应可独立执行，预期结果同时包含接口/页面结果和必要的 OSS、临时文件或业务数据检查。

## 覆盖范围

- 图片白名单：jpg、jpeg、png、gif、webp。
- 非白名单：bmp、tif、svg、psd、ico。
- 真实图片校验、空文件、伪造后缀和总像素上限 50,000,000。
- 相册类文件 5MB 边界。
- 视频类文件 20MB 边界、MP4、首帧封面、水印和 ffmpeg 异常。
- 原图像素与 MD5、700/360/240/60 派生图、展示 URL 的 resize 参数。
- 单文件和批量上传、部分成功清理、本地临时文件清理。
- CDN URL、对象路径和逗号分隔多文件删除。
- OSS 鉴权、网络、超时异常及关闭 OSS 后的本地流程。
- 评价、售后、商品、房源、充值订单等业务记录和前后台展示闭环。

## 验收标准

- 工作簿包含全部五个工作表，表头清晰、冻结首行、启用筛选并合理设置列宽和自动换行。
- 核心用例不存在缺失的编号、标题、步骤或预期结果。
- 业务入口全部纳入回归矩阵，且覆盖要求符合文档约定。
- 汇总统计使用公式或可审计的表格数据，不硬编码无法追溯的汇总结果。
- 工作簿无明显公式错误，所有工作表均通过渲染检查，关键内容无严重截断。
- 最终文件保存到本次任务的 `outputs` 子目录。
