# 外卖安全结算审查与验证报告

- 外卖入口已将“结算预览”和“真实下单”分开。
- 不带 `--checkout` 时只执行外卖导航和进店。
- `--checkout` 会准备结算页，但在第二次最终确认前返回，不创建订单。
- 只有 `--checkout --submit-order` 能继续真实提交。
- 单独使用 `--submit-order` 会在 Driver 创建前返回退出码 `2`。
- CLI 已删除 `--password`，页面流已删除自动输入支付密码的方法和固定密码默认值。
- 余额真实提交后由用户在真机手动输入密码；脚本只等待订单详情，不接收、不记录密码。
- 货到付款仍需 `--submit-order`，但不进入手动密码等待。

## 已覆盖的业务顺序

### 结算预览

进店 → 选择分类 → 加购 → 进入结算 → 选择地址 → 优惠券/备注/通知设置 → 支付方式 → 配送时间 → 在最终确认前停止。

离线测试断言预览模式只调用一次确认入口，不进入手动支付等待、订单详情断言或取消订单。

### 显式余额提交

结算准备 → 第二次最终确认 → 等待用户真机手动输入支付密码 → 检测订单详情 → 取消订单。

离线测试覆盖手动等待成功和超时分支；超时时不会继续执行取消操作。

### 显式货到付款

结算准备 → 第二次最终确认 → 跳过密码等待 → 检测订单详情 → 取消订单。

## 本阶段没有验证的内容

- 没有执行真实下单、支付或取消订单。
- 没有输入或读取真实支付密码。
- 没有验证当前测试环境是否支持余额支付或货到付款。
- 没有验证真实优惠券、配送时间、地址弹层、订单详情和取消接口的兼容性。
- 没有基于真机页面树证明现有定位器在所有 App 版本中稳定。

这些项目必须结合明确的设备、App 版本、账号状态和当次授权后才能下结论。

## 剩余风险

- 本次扫描的 8 个外卖文件仍有 `151` 处固定等待和 `231` 处宽泛异常捕获。
- 超过 800 行的外卖文件有 3 个：
  - `pages/takeout_checkout_mixin.py`：`2821` 行；
  - `pages/takeout_page.py`：`1085` 行；
  - `pages/takeout_cancel_order_mixin.py`：`1085` 行。
- 固定等待仍可能在慢设备上提前结束、在快设备上造成空耗。
- 宽泛异常可能混淆可选元素缺失、页面状态错误、WebView 切换失败和 UiAutomator2 故障。
- `--checkout` 会执行加购和结算准备，可能在当前账号购物车留下测试商品，因此不属于严格的无业务数据变化验收路径。
